# AgentHost 需求文档

开发一个远程 Codex CLI 管理工具。后端使用Go。前端基于：https://www.assistant-ui.com/

## 目标

通过一个远程管理界面，让用户能够查看、管理和控制 Codex CLI 的任务执行过程。

## 界面要求

- 整体交互和视觉体验参考 Codex 聊天界面。
- 以聊天消息的方式展示用户请求、Agent 回复和任务执行过程。
- 清晰显示 Agent 当前正在做什么。
- 实时显示 Agent 的思考状态、任务阶段、工具调用和执行进度。
- 执行过程应与最终回复关联在同一个任务上下文中。
- 支持展开和查看详细执行信息。

## 核心能力

- 提供单独的启动脚本，启动自动安装依赖，一般在容器中部署
- 提供远程 Web 管理界面。
- 支持连接和调用 Codex CLI。
- 支持根据 Markdown 格式的 workflow 文档执行任务。
- Workflow 可以描述任务步骤、执行顺序、任务依赖和调用规则。
- 工具能够根据 workflow 调用其他任务或 Agent。
- 支持查看任务状态、执行进度和执行结果。
- 支持查看 Codex CLI 的完整命令执行过程和运行日志。
- 支持查看 Agent 调用的具体命令，包括命令参数、工作目录、标准输出和错误输出。
- 支持管理多个任务和任务会话。
- 支持远程启动、暂停、停止和查看任务。

## 执行过程展示

任务执行期间，界面需要实时显示：

- Agent 当前正在执行的动作。
- 当前任务阶段和进度。
- 调用的工具或其他任务。
- 实际执行的命令。
- 命令参数和工作目录。
- 命令输出和错误信息。
- 每一步的执行状态。
- 最终执行结果。

## 基本流程

1. 用户通过远程管理界面提交或选择一个 Markdown workflow。
2. AgentHost 解析 workflow 内容。
3. AgentHost 根据 workflow 调度 Codex CLI 和其他任务。
4. Agent 执行期间，界面实时展示 Agent 正在做的事和调用的命令。
5. 用户可以查看完整任务链路、命令输出、状态变化和最终结果。
